# Security

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/membraince/membraince-code/security/advisories/new).
Don't open a public issue for a security problem.

This repository holds the client integrations. Reports about the MemBraince service itself
(membraince.com) are welcome through the same form. We'll acknowledge a report within a few
days and keep you updated until it's resolved.

Never include a real API key in a report, issue, or pull request. If you exposed one, revoke it
in the portal at https://membraince.com/portal.
